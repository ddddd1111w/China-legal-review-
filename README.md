# China-legal-review-
# 面向 LLM Agent 的中国法律法规检索与合法性审查技能（DSH Skill）  本技能适配 DeepSeek、智谱 GLM 等大模型 Agent。内置现行有效法规1500余部、约750 万字，涵盖宪法、法律、行政法规、监察法规、司法解释，未收录地方性法规、部门规章、地方政府规章及规范性文件；地方细则未入库将标注未覆盖。运行逻辑：优先检索本地文库法条原文，引用载明法名、条号、施行日期，不杜撰法条，避免条号错引、旧法误用。可对规范性文件、行政行为、执法决定、处罚、许可、行政强制案件、合同、制度文稿开展合法性审查，研判效力位阶、新旧法、特别法冲突及溯及力，输出审查意见。技术特点：纯 Python 标准库实现，零第三方依赖，支持法规增删替换、增量建索引；技能自包含、路径自适应，复制即用
