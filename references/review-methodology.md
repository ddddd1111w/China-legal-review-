# 合法性审查方法论

> 适用两类任务：**A. 合法性审查**（对规范性文件、行政行为、执法决定、合同/制度文稿等出具审查意见）；**B. 法律问题思考**（法律咨询、定性、办案思路）。
> 方法论只给框架；每一个法律判断都必须回到文库原文条文，框架不替代检索。

## 1. 总流程（七步法）

1. **收材与定性**：确认审查对象是什么（规范性文件 / 具体行政行为 / 合同 / 内部制度 / 个案）、所处阶段（起草中、已作出、复议诉讼中）、送审方要什么结论。材料不全先列补充清单，不要带缺口硬审。
2. **拆解审查点**：把对象拆成最小单元——文件按"章/条/款/项"拆，行为按"立案—调查—告知—决定—送达—执行"拆，合同按条款拆。
3. **逐点定位依据**：对每个审查点用 `search_law.py` 检索（先 titles 定法、再 search 定条、必要时 get 读全条）。一个审查点通常同时需要"设定依据 + 实施依据 + 程序依据"。
4. **比对分析**：把对象表述/行为与法条逐项对照，区分"符合 / 不符合 / 无依据 / 依据冲突 / 裁量空间内"。
5. **效力与时效校验**：按 `conflict-rules.md` 核位阶、核新旧、核施行日期、核是否被修改。
6. **分级下结论**：按第 5 节口径逐点定性，再给总体结论。
7. **出具意见**：按 `report-template.md` 成文。每个否定/风险意见 = 问题定位（第几条第几款）+ 违反的依据（法名+条号+原文要点）+ 理由 + 修改建议。

## 2. 通用审查维度

对任何审查对象，依次过七个维度：

| 维度 | 审查问题 |
|---|---|
| **主体** | 作出机关/组织是否具有法定资格？是否法定职权机关或法律法规授权组织？受委托组织是否有合法委托依据、是否以委托机关名义？执法人员是否持证、人数是否合法定要求？ |
| **权限** | 是否在法定职权范围内？有无越权（事项越权、级别越权、地域越权）？是否行使了应由其他机关行使的权力？合议/审批/集体讨论权限是否正确？ |
| **程序** | 立案、调查取证、告知（事实理由依据+权利）、听取陈述申辩、听证、回避、法制审核、集体讨论、审批、文书制作、送达、期限、执行方式是否齐备且顺序正确？ |
| **事实证据** | 事实是否清楚，证据是否确实充分、合法取得、与待证事实相关联？证据链能否闭合？待证事项与法条构成要件是否一一对应？ |
| **依据** | 引用依据是否现行有效、位阶足够、与事项对应？条号款号是否准确？是否存在无依据设定义务/减损权利？ |
| **内容** | 设定的权利义务是否合法、适当？裁量是否在法定幅度内、是否显失公正、是否符合比例原则（适当、必要、均衡）？是否违反一事不再罚等原则？ |
| **形式** | 文书种类、格式、签章、日期、告知救济途径与期限（复议60日/诉讼6个月等，以原文核验）是否规范？ |

## 3. 行政规范性文件合法性审核要点

审核规范性文件（涉及公民法人权利义务、反复适用的公文）时重点查：

1. **制定主体**：是否为有权制定的行政机关；内设机构、临时机构、议事协调机构不得以自己名义印发。
2. **事项边界**（高频违法点）：不得违法设定——
   - 行政许可、行政处罚、行政强制、行政征收收费；
   - 机构编制、经费；
   - 不得违法增加公民/法人义务、减损权利或增加本机关权力。
3. **依据**：每条措施能否追溯到法律、法规、规章或上级文件的明确授权；"根据有关法律法规"这类空泛表述不算依据。
4. **程序**：评估论证、公开征求意见、合法性审核、集体审议决定、公开发布等环节是否履行；未经公布不得作为行政管理依据。
5. **内容与衔接**：与同位阶及上位文件是否冲突；是否违法设置市场准入、排除竞争；有效期、施行日期、解释主体是否明确。
6. 审核结论只对"是否合法"发表意见，合理性、可行性问题可另提建议但不混入合法性结论。

## 4. 常见具体行政行为审查要点

### 4.1 行政处罚（以《行政处罚法》为一般法，检索各专门法的特别规定）
- 处罚主体与管辖权；执法人员不少于两人、出示证件；
- 处罚依据是否事先公布、行为时是否有效；
- 不予处罚、从轻减轻、从重情节的认定与证据；
- 告知、陈述申辩、**不得因申辩加重处罚**；符合条件的听证是否告知并组织；
- 简易程序（当场处罚）适用条件与限额；一般程序、法制审核（**重大处罚决定法制审核**）、集体讨论；
- 一事不再罚（同一违法行为不得给予两次以上罚款）；
- 处罚与教育相结合、首违可以不罚等制度；
- 当场收缴罚款的法定情形；罚缴分离；
- 决定书必备内容与救济告知；送达与执行、加处罚款（滞纳金）上限（不超出本金）。

### 4.2 行政许可（《行政许可法》）
- 设定权限：法律、行政法规、国务院决定、地方性法规、省级政府规章（临时，期限一年）；其他规范性文件一律不得设定；
- 实施主体、委托实施、统一办理；
- 申请受理（一次性告知补正）、审查、期限（当场/20日/延长10日等，以原文核验）、听证（依职权/依申请）、变更延续（逾期视为准予延续）；
- 不得违法收费；特许的招标拍卖；撤销、撤回、注销的法定情形与补偿。

### 4.3 行政强制（《行政强制法》）
- 行政强制措施 vs 行政强制执行的区分；
- 设定权限：强制措施由法律、行政法规（特定种类）、地方性法规（特定情形）设定；**行政强制执行只能由法律设定**；
- 实施主体资格（不得委托给无资格人员/组织）；
- 程序：报批、两人以上、出示证件、当场告知、听取陈述申辩、制作现场笔录；
- 查封扣押的对象范围、期限、保管、解除；冻结的期限与程序；
- 加处罚款/滞纳金的催告（催告满10日才可强制执行，以原文核验）、代履行、申请法院强制执行的期限与材料。

### 4.4 行政检查/日常监管
- 是否有法定检查依据与年度计划/"双随机、一公开"要求；
- 检查频次、方式、记录、人员证件；不得妨碍正常生产经营、不得索取收受财物；
- 发现问题后的移送、责令改正与后续处罚衔接。

### 4.5 行政征收征用、行政确认、行政裁决、信息公开
- 逐项检索专门法律法规；信息公开案件重点核：主动公开目录、依申请公开程序、答复期限、法定不公开事项（国家秘密/商业秘密/个人隐私）、滥用申请权处理。

## 5. 审查结论分级

对每个审查点和总体结论，使用五级口径，避免含糊：

- **合法**：主体、权限、程序、事实、依据、内容、形式均符合现行法。
- **不合法（违法）**：明确抵触某条现行有效规定，或无法定依据、超越权限、严重违反法定程序。必须指明违反的具体条文。
- **部分不合法**：部分条款/环节违法，其余合法；逐项列明。
- **存在法律风险/依据不足**：不直接违法，但依据不充分、规定不明确、裁量可能失当、与司法实践可能冲突；说明风险点和补正建议。
- **无法判断（待补充）**：材料或依据缺失，列明需要补充的材料/需要查明的问题。

措辞纪律：区分"违反"与"可能违反"、"无效"与"可撤销/可确认违法"；审查意见一般不替有权机关宣告文件无效或行为无效，而是建议纠正、撤销、补正或提请有权机关处理。

## 6. 高频问题快查清单（行政执法场景）

接到审查任务先对照本清单建立检查轴，再去文库逐条核实：

1. 有没有职权依据？是否跨部门、跨层级、跨地域？
2. 行为类型是什么？该类型的设定依据与实施依据分别是哪部法？
3. 程序节点是否齐全、顺序是否正确、期限是否超期？
4. 权利告知（陈述申辩、听证、复议诉讼）是否到位？
5. 证据是否在作出决定前收集并经质证/核对？
6. 裁量是否在幅度内、说理是否体现裁量理由？
7. 是否存在以规范性文件自我授权、以罚代管、选择性执法？
8. 引用法条是否精确到条/款/项且为现行有效文本？
9. 文书签章、日期、送达回证是否完整？
10. 涉及两法衔接（行刑衔接）、复议诉讼风险点是否评估？

## 7. 法律问题咨询（B类任务）的处理框架

1. **提炼法律问题**：把用户口语化描述转成规范问题（主体—行为—法律关系—争议点）。
2. **确定法域与基本法**：先 titles 定位部门法，再 search 关键制度条文；必要时用司法解释核验裁判口径。
3. **要件分析**：写出法条构成要件，与事实要件逐项涵摄；事实不明的，列出不同事实假设分别分析。
4. **程序与救济**：说明时效、管辖、救济途径与期限（数字一律以文库原文核验）。
5. **结论分层**：确定结论 / 通说观点 / 存在争议（列分歧）/ 信息不足；不编造法条和判例。
6. 输出风格：先给直接结论，再给依据链条和操作建议；引用条文用书名号+条号，并标注施行日期。
